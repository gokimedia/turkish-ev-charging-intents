# Contributing

Thank you for helping improve the Turkish EV Charging Intent Dataset.

## What makes a useful contribution

- Natural Turkish phrasings that add linguistic variety without copying user logs.
- Coverage for spelling errors, regional expressions, code-switching, or multi-intent requests.
- Corrections to labels, documentation, metadata, or accessibility.
- Reproducible baselines and error analyses.

Do not contribute personal data, customer conversations, private logs, copyrighted query exports, secrets, or examples that identify an individual.

## Workflow

1. Open an issue describing the proposed change.
2. Keep dataset changes focused and explain their provenance.
3. Run `npm test` before opening a pull request.
4. Update `CHANGELOG.md` when behavior, labels, or records change.

By contributing dataset content, you confirm that you have the right to submit it under CC BY 4.0.
