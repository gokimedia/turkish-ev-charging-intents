# Figshare distribution

This directory contains the publication metadata for the Figshare mirror of the
Turkish EV Charging Intent Dataset.

## Files to upload

- `data/train.jsonl`
- `data/validation.jsonl`
- `data/test.jsonl`
- `data/stats.json`
- `distribution/kaggle/turkish-ev-charging-intents.csv`
- `metadata/croissant.json`
- `README.md`
- `DATASHEET.md`
- `CITATION.cff`
- `LICENSE`

## Publication settings

- Item type: Dataset
- License: CC BY 4.0
- Version: 1.0.0
- Primary language: Turkish
- Canonical DOI: `10.5281/zenodo.22062688`
- Figshare DOI: `10.6084/m9.figshare.33317592`
- Public record: https://figshare.com/articles/dataset/Turkish_EV_Charging_Intent_Dataset/33317592

Use the values in `metadata.json` for the public record. Add the Zenodo DOI,
GitHub repository, TekPedal documentation, Hugging Face, Kaggle, and OpenML as
Related Materials so the links are also exposed through DataCite-compatible
metadata.

The public Figshare item URL is included in the repository metadata and the
TekPedal open-data page.
